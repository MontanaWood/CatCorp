# CatCorp Messenger

CatCorp Messenger — локальный корпоративный мессенджер для общения в локальной сети.
Проект состоит из отдельного Python-сервера, MySQL/MariaDB базы данных и PyQt6-клиента, который можно запускать как обычный Python-скрипт или собрать в самостоятельный `.exe`.

## Возможности

* регистрация и вход пользователей;
* автоматический вход по токену, если включено «Запомнить вход»;
* личные чаты;
* групповые чаты;
* непрочитанные сообщения;
* закрепление и скрытие личных чатов;
* уведомления в системном трее;
* настройка звука уведомлений;
* настройка скрытия текста уведомлений;
* статусы пользователя;
* профиль пользователя;
* отдел и должность в профиле;
* мини-профиль собеседника;
* ответ на сообщение;
* редактирование своих сообщений;
* запрет редактирования сообщений старше 48 часов;
* индикатор печати;
* выход из текущего чата по `Esc`;
* встроенный дефолтный сервер `127.0.0.1:5000`;
* настройка host/port сервера через кнопку «Сервер» на экране входа;
* сборка клиента в самостоятельный `.exe`.

## Стек

* Python
* PyQt6
* TCP sockets
* JSON protocol
* MySQL / MariaDB
* XAMPP
* PyInstaller

## Запуск сервера

Перед запуском клиента должен быть запущен сервер:

```powershell
python server.py
```

По умолчанию сервер слушает:

```text
0.0.0.0:5000
```

## Запуск клиента

```powershell
python client.py
```

На экране входа можно нажать кнопку **«Сервер»** и указать IP компьютера, на котором запущен `server.py`.

## Сборка клиента в exe

```powershell
pyinstaller --noconfirm --onefile --windowed --name CatCorpClient client.py
```

Готовый файл появится здесь:

```text
dist/CatCorpClient.exe
```

## Локальные файлы рядом с exe

Минимально рядом с `.exe` может лежать только сам клиент:

```text
CatCorpClient.exe
```

Дополнительные файлы создаются только при необходимости:

```text
auth_token.json
settings.json
server_config.json
```

`auth_token.json` создаётся только если включено **«Запомнить вход на этом ПК»**.
`settings.json` создаётся после изменения настроек.
`server_config.json` создаётся после изменения host/port через кнопку **«Сервер»**.

## Безопасность

* клиент не подключается напрямую к базе данных;
* пароль не хранится в открытом виде;
* токен входа не вшивается в `.exe`;
* токен создаётся только при включённой настройке «Запомнить вход»;
* изменённый host/port хранится локально в `server_config.json`.

## Проверка в локальной сети

1. Запустите `server.py` на основном компьютере.
2. Узнайте IP этого компьютера:

```powershell
ipconfig
```

3. На другом ПК запустите клиент.
4. На экране входа нажмите **«Сервер»**.
5. Укажите IP компьютера с сервером и порт `5000`.

Проверка порта:

```powershell
Test-NetConnection 192.168.1.25 -Port 5000
```
